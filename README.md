# 🎓 Nexus AI • Personal Study & Document Assistant

An AI-powered academic study companion and document analyst built with a **FastAPI** backend, **Streamlit** frontend, and **Google Gemini API** integration. It features automated Python tool-calling for academic calculations and a custom butter-yellow SaaS UI.

---

## ✨ Key Features

- **📄 Document Knowledge Base (PDF RAG):** Upload syllabi, lecture notes, or resumes to query specific context directly using Google Gemini.
- **🛠️ Automated Tool Calling:** Automatically detects academic queries and triggers custom Python functions (e.g., computing Semester Grade Point Average / SGPA).
- **⚡ Modern Tech Stack:** High-performance asynchronous backend routing via FastAPI coupled with an interactive web UI built in Streamlit.
- **🎨 Custom UI Theme:** Designed with a warm butter-yellow canvas (`#FFF9DB`), soft cream message cards, and warm brown accents.

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, Uvicorn, PyPDF2
- **Frontend:** Streamlit, Custom CSS
- **AI / LLM:** Google GenAI SDK (`gemini-3.5-flash-lite`)
- **Environment Management:** `python-dotenv`
